# Organização dos resultados

Os artefatos são separados pela natureza do experimento:

- `synthetic/`: benchmark dos nove cenários sintéticos. Contém `checkpoints/`, `tuning/`, `tables/`, `figures/`, `logs/` e `backups/`.
- `applied/`: estudo aplicado 8D. Contém `reference_8d/`, `applied_8d_equal_budget/`, `comparison_8d_corrected/` e `logs/`.

Os caminhos gravados em tabelas e manifests são relativos à raiz do repositório e usam essa mesma estrutura.
